## 流程覆盖

空项目 → 人群简报 → 素材与评论 → 有依据的方向 → 已确认剧情和 4×6 秒镜头 → 资产回传、定稿与绑定 → 冻结 ZIP 提交包 → 真实 MP4 回传与媒体分析 → 逐镜审片选用 → 剪映素材 ZIP 与 SRT → 1080×1920 成片回传与自动/人工确认 → 授权和质检归档 → 发布登记与 CSV → 留存和复盘 → 下一条草稿。

边界用例涵盖重复提交/上传、预算暂停、引用与能力错误、坏文件和坏 SRT、历史候选/成片失效、备份恢复、ZIP 路径、加密凭证、模板版本、CSV 缺失与重复、评论隐私、增强和商品指定镜头替换、选题库证据追溯。

## 真实调用边界

媒体为 FFmpeg 合成验收素材；LLM 为本地协议模拟服务。没有调用付费视频/图片模型，也没有代替用户到剪映剪辑或在内容平台发布。真实模型输出质量、用户 API 账号和官网当期参数不在自动测试通过的含义内。
