## 本次可操作功能

- 左侧「七步制片」：首片38秒实录，8张图、8段原始视频、逐镜生图参考词、真实Wan提交词和即梦迁移词；同时标明源视频与导出规格、费用未知和人工审核待完成。
- 「用此分镜新建项目」：复用用户选定A角色与8镜草稿，生成独立项目；不复制历史审片结论，不创建虚构候选或效果数据。
- 「七步制作」：每步工具、产物、参考词、人工检查和失败经验。模型版本与价格由会员界面核验，不预填即梦账户能力。
- 逐镜保存生图词与动态图词、生成档位，回传/替换独立首帧，四项人工审图；审核绑定图像哈希、生图词与角色版本。更改输入后旧审核失效。
- 首帧图生视频提交包只上传已审首帧，角色引用保留为身份依据；不强迫额外上传同一场景和道具图片。沿用前四阶段关卡和冻结提交包机制。
- 模型档案可选择「会员积分」；有预计积分但没有人民币换算时可准备提交包。回传真实扣分，待核费用显示待核价，CSV留空，不当作零成本。提交包固定当时的换算参数。
- 剪映素材包附分镜图、两种提示词与源视频规格，保留视频真实扩展名。新流程成片增加商用范围人工确认，拒绝已标记不适合商用的声音资产。

会员生成仍在即梦官网完成；没有接入会员后端 API，也不会自动启动收费生成。剪映导出的是素材交接包，不是未验证的剪映原生工程。

## 建议验收顺序

1. 打开「七步制片」播放38秒首片，再切换第2、第6、第8镜查看源片和提示词。
2. 点击复制建立草稿，检查8镜与A版身份、所有审核保持待确认。
3. 进入「七步制作」，逐镜修改并保存生图词/动态图词，勾选四项人工审图后记录；改图或生图词应要求重新审核。
4. 在设置里按即梦实际界面建立模型档案：模式填写 `首帧图生视频`，填写支持时长、画幅、分辨率、参考图上限、核对日期，会员选择积分记账。这里不附造假的账户测试结果。
5. 确认简报、调研、剧情与镜头检查，确认资产关卡；检查提交包后，在即梦手动生成、回传审片，再进入剪映交接。
6. 成片回传后完成技术检测、完整视听和权益确认；本轮验收不等于授权发布。

## 首片素材安装与迁移

大文件不入 Git；源码内的 `catstudio/resources/pet-campus-001.json` 固定白名单与 SHA256。只有19个指定素材可安装，不包含非商用测试配音、凭据、账单或工作站绝对路径。

```powershell
.\.venv\Scripts\python.exe scripts/install_first_example.py <首片episode目录>
```

默认安装至仓库忽略的 `sample-media/pet-campus-001`。也可加 `--destination <素材根目录>`，同时设置 `CATSTUDIO_EXAMPLES_DIR` 为该根目录。缺少素材时仍可阅读分镜和提示词；复制按钮不可用，接口返回明确错误，不生成空项目。

域名部署前把已校验的素材目录放到持久化磁盘，例如 `/var/lib/catstudio/data/examples/pet-campus-001`，设置 `CATSTUDIO_EXAMPLES_DIR=/var/lib/catstudio/data/examples`；现有数据卷可沿用。19项素材校验清单随源码，不从外站下载文件。普通升级不需要重建原数据库结构，新增字段存于现有 JSON 数据中。

本地预览可设置 `CATSTUDIO_DATA` 指向独立目录、`CATSTUDIO_DIST` 指向隔离构建的 dist，并在127.0.0.1:8777启动。不要把验收数据库覆盖到生产库。

## 明确的验收边界

当前首片采用 imagegen + 本地 Wan2.1 + FFmpeg；即梦词是迁移参考，未在账户实测。源视频480×848/16fps，导出1080×1920/30fps不等于原生高清。首片未发布，没有爆款或收入证据。具体账户的速度、扣分、生成质量和剪映素材权益仍需在下一条真实制作中记录。
