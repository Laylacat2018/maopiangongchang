# 猫片工场开发自测报告

测试日期：2026 年 11 月 4 日。需求依据为用户上传的 PRD v2.1-cc 半手动版。测试环境为当前 Windows 电脑、SQLite WAL、本地 FFmpeg/ffprobe、Vue 生产构建；具体 Python 依赖版本见根目录 requirements-tested.txt，前端依赖见 package-lock.json。

本轮覆盖了从创建项目到复盘生成下一条草稿的完整本地流程。19 个自动化场景全部通过；另在浏览器实际操作了创建项目、简报保存与确认、链接导入、故事方向、剧情确认、分镜编辑、素材上传、新版本创建和定稿，并逐页检查核心界面与配置页。隔离验收项目中的 H.264/AAC 视频在浏览器成功加载，视频 readyState=4、时长 6 秒、分辨率 360×640，逐帧按钮将播放位置推进 1/30 秒，候选并排对比正常。浏览器控制台未发现运行错误。

## 浏览器检查

- 工作台、项目列表、简报、调研、剧情分镜、资产库、模型选择、绑定、回传审片、商品支线、镜头进度、剪辑准备、成片交付、复盘、模型档案、LLM 配置、模板、备份和预算页面均已打开检查。
- 从空项目实际创建，填写人群后确认阶段，导入手录测试来源，保存有引用依据的方向，确认剧情并新增分镜，自动时间区间和检查状态正确。
- 通过浏览器文件选择器上传本地测试 PNG，回传为新版本并设为定稿，图像预览和版本锁定提示正确。
- 绑定未齐、模型未配置时，校验面板明确展示阻断原因，不生成假候选或假进度。
- 已检查桌面三栏布局；已修复中等宽度下最后一张项目卡被误隐藏的问题。移动端不是此版验收目标。

## 本轮修复

1. SQLAlchemy 提交后字段过期导致接口返回空对象：改为显式属性序列化。
2. Windows 备份数据库连接未关闭导致文件占用：显式关闭连接，使用唯一临时文件。
3. 恢复备份后保留了备份任务的“运行中”状态：恢复时将未完成任务标记为历史中断，防止阻塞后续操作。
4. 表单嵌套 label 导致下拉框/检查项标识不清：修正结构并增加明确标签。
5. 资产与提示词变化后旧选用、旧成片仍可能显示当前状态：增加失效与历史标记及确认前比对。
6. CSV 多行与统计口径处理：增加对应行选择、缺失指标处理、幂等导入与历史统计窗口切换。
7. 不合格成片的 SRT 越界曾使整项任务失败而丢失其他检测结果：改为保留逐项检测结果并阻断交付。
