# 猫片工场本地验收指南

访问 http://127.0.0.1:8776 。本版以新版 PRD 的半手动工作流为准。第一次验收建议做一条 24 秒、4 镜、9:16 的短片。AI 文本功能是可选辅助，没有 API Key 时可以手写剧情和提示词。

## 准备

准备一个角色图、一个场景图、一个道具图、可合法使用的声音，以及官网生成的候选视频和剪映导出的成片。测试素材仅用于操作验收时，应在素材来源与项目名称里注明“测试”。

“模型档案与设置 → 模型档案”中按官网填写真实版本、支持模式、参考图和音频上限、时长档位、分辨率、画幅、每候选积分、每积分人民币及核对日期。720p/1080p 等字符串须与生成偏好保持一致。默认档案故意不预填能力和价格，避免误导。

## 从零到一操作

| 步骤 | 操作 | 应看到的结果 |
|---|---|---|
| 1 | 新建项目，填目标人群，选平台、画幅、20–30 秒、预算 50 元，确认简报 | 草稿刷新仍在，进入素材调研 |
| 2 | 导入一个链接，手录一条评论，创建并选中故事方向，引用刚登记的素材，确认选题 | 引用可追到原素材，没有虚构搜索结果 |
| 3 | 手写剧情并确认，添加 4 个 6 秒镜头，填写动作、结束状态、声音、心声和提示词，完成每镜 3 项检查 | 时间区间自动为 0–6、6–12、12–18、18–24 秒 |
| 4 | 创建 CHAR 角色、SCN 场景、PROP 道具；逐一“回传新版本”，登记来源后定稿 | 版本显示定稿，原文件不可原地替换；声音资产缺授权会报错 |
| 5 | 在资产需求清单为每镜的主体、场景、道具分配相应定稿版本，确认资产 | 未定稿或错类型不能绑定；缺项阻止关卡 |
| 6 | 选择已核对模型，保存模式、分辨率、候选数和音频策略 | 项目默认与逐镜覆盖分开 |
| 7 | 单镜绑定页校验，检查最终提示词、上传顺序与参数，确认估算后导出 | 下载 ZIP 含 submission.md、manifest.json 和按序命名的真实素材 |
| 8 | 在官网粘贴提示词、按说明上传素材、手动选择 @ 主体并生成；下载视频 | 官网操作由你完成，平台没有自动生成进度 |
| 9 | “提交与审片”回传视频到对应冻结记录，填实际积分/金额 | 后台显示时长、分辨率、帧率、音轨与参数差异；可抽帧、逐帧或并排对比 |
| 10 | 四项审片全部检查后选用；若不合格，标记时间点并淘汰或重写 | 每镜只选用 1 条，旧候选不删除 |
| 11 | 对全部镜头完成以上步骤，确认视频阶段 | 看板为 4/4 已选用，可进入剪辑准备 |
| 12 | 检查顺序连播、SRT 与声音要求，导出剪映素材包 | ZIP 有 4 条按序命名的视频、声音文件、SRT、剪辑说明和清单 |
| 13 | 在剪映完成配音、音乐、字幕和剪辑，按 1080×1920 等目标规格导出 MP4，回传 | 自动检查画幅、分辨率、时长、音轨、黑帧、静音与字幕 |
| 14 | 完整观看、实际试听、核对字幕同步，完成 3 项确认 | 仅自动与人工检查均通过才标记可发布；可打包归档 |
| 15 | 手动发布并登记链接和对应成片，导入平台 CSV | 映射字段、选择对应数据行与统计窗口，预览后确认 |
| 16 | 登记真实留存采样点、录评论，写观察、假设、依据与单变量实验 | 无数据不生成假曲线，缺失指标不作 0 |
| 17 | 保存复盘，创建下一条简报 | 继承受众、时长与可复用资产，只创建草稿，不生成视频或发布 |

## 建议重点试的异常

- 目标人群留空确认简报：应阻止，并保存已填草稿。
- 仅做 2 项分镜检查：不能确认分镜。
- 模型档案未核对、参考图超限、24 秒镜头与档位不符：不能导出，明确说明原因。
- 上传损坏的 PNG：不能作为有效资产保存。
- 新建角色 v2 并定稿：原镜头仍绑定 v1。明确换绑后，原选用候选回到历史状态。
- 四项审片不全：不能选用。重新选用另一候选，旧选用应成为备选。
- 重复上传同一候选到同一记录：不重复存文件、不重复入账。
- 月预算设为 0 并开启暂停：禁止新的提交包导出；已有文件可下载。
- 上传 6 秒低分辨率视频作为 24 秒成片：检测应失败，不能可发布。
- 修改已交付项目的绑定或提示词：旧成片保留下载，标为历史，不冒充当前通过版本。
- 相同 CSV、映射、统计窗口与数据行再导入：不重复累计；缺失分母时互动率不虚构。
- 下载备份、另建测试项目后恢复：恢复到备份时刻；当前恢复前数据另有安全备份。

## 验收范围说明

自动测试验证的是本地业务规则、真实文件流转和媒体检测，LLM 接入用本地 HTTP 协议服务验证。真实大模型账号的输出质量、官网当前价格与实际猫咪动作质量仍需你的生产素材验证。剪映原生草稿工程为 P1 待兼容性验证，本版交付通用素材包。
